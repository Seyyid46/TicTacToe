Tic-Tac-Toe Terminal Game

Overview

This is a simple Tic-Tac-Toe game implemented in Java that can be played directly in the terminal. 1 player take turns to mark the spaces in a 3x3 grid. The player who succeeds in placing three of their marks in a horizontal, vertical, or diagonal row wins the game.

Features

	•	One-player mode: Play against Computer (random) in turn-based gameplay.
	•	Terminal-based UI: The game runs in a terminal window and uses simple text-based input/output.
	•	Input validation: Ensures that players can only make valid moves and prevents overwriting moves.

How to Play

	1.	Start the Game:
	•	Compile the Java code and run the resulting class file to start the game.
	2.	Game Instructions:
	•	The game board is represented as a 3x3 grid with positions numbered 1 through 9 as follows
  •	Players take turns to input the number corresponding to the position where they want to place their mark (X or O).
  	3.	Winning the Game:
	•	The first player to align three of their marks in a row (horizontally, vertically, or diagonally) wins the game.
	•	If all 9 positions are filled and no player has aligned three marks, the game ends in a draw.
	4.	Ending the Game:
	•	Once the game is over, the program will announce the result and terminate.

Requirements

	•	Java Development Kit (JDK): Ensure that you have JDK 8 or higher installed to compile and run the Java code.

Compilation and Execution

	1.	Compile the code:
	•	Open your terminal and navigate to the directory containing the TicTacToe.java file.
	•	Run the following command to compile the code:
 javac TicTacToe.java
 	2.	Run the game:
	•	After compilation, execute the program using the following command:
 java TicTacToe
 	3.	Follow the on-screen instructions:
	•	The game will prompt player to enter his move.
